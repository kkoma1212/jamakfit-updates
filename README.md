# 자막핏 설치 파일·새 판

대본(PDF)과 완성 영상을 넣으면 자막을 먼저 달아 주는 Windows 프로그램 **자막핏**의 설치 파일과 새 판을 두는 곳입니다. 소스 코드는 여기 없습니다.

> 지금은 **시험판(0.9)** 입니다. Windows 11 PC 한 대에서만 확인했어요.

## 설치

1. 오른쪽 **Releases**에서 가장 새 판의 `jamakfit-setup-<판>.exe`를 받습니다.
2. 실행하면 `Windows의 PC 보호` 창이 뜰 수 있어요(코드 서명 인증서가 아직 없어서). **추가 정보 → 실행**을 누르면 됩니다.
3. 처음 켜면 자막을 알아듣는 인식 모델(1.6GB)을 받습니다. NVIDIA 그래픽카드가 있으면 그래픽카드 부품(1.4GB)도 받아요. 다 받을 때까지 첫 화면에 진행 막대가 보입니다.

- 필요한 것: Windows 10/11 64비트, 디스크 여유 약 5GB(작업 영상 공간 별도)
- NVIDIA 그래픽카드가 없어도 됩니다. 다만 알아듣는 속도가 느려요.
- 관리자 권한 없이 `%LOCALAPPDATA%\자막핏`에 설치되고, `설정 → 앱`에서 지울 수 있어요.

## 새 판

자막핏은 켤 때 이곳의 `release.json`을 확인해 새 판을 받아 둡니다. 받은 판은 **다음에 켤 때** 바뀝니다. 새 판에는 운영자의 서명이 있어서, 서명이 맞지 않는 파일은 받지 않아요. 새 판으로 켜지지 않으면 직전 판으로 되돌아갑니다.
